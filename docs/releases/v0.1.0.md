# v0.1.0 — Local LLM factor research, with reward controls

This experimental release makes the completed financial proposal study
inspectable and runnable. It includes the code and all saved outcomes for five
frozen policies: one SFT model, two correctly rewarded RLOO runs, and two
on-policy reward-permutation controls.

The attached `financial-adapters-v1.zip` contains the exact five LoRA adapters
and configurations used in the published evaluation, plus the model card and
Apache-2.0 attribution. It does not include base weights, market data or
tokenizers. Use the pinned Qwen3-0.6B revision recorded in the manifest.

Correctly rewarded RL improved aggregate reward over both SFT and the matched
permutation controls, but the two seeds' predictive-IC contrasts have opposite
signs. Fewer invalid formulas explain much of the original reward improvement.
Every sampled policy remains below the uniform formula-grid reference, and
greedy behavior is identical. The sequential evidence-acquisition gate failed
and that controller-training branch stopped.

These are small development experiments on revised industry-portfolio
histories, not demonstrated profitable alpha or a useful learned multistep
financial agent. The two control runs were an exploratory follow-up after the
original results, with their own pre-evaluation freeze. Negative findings,
failed gates, exact source and checkpoint hashes, and internal AI review scope
are retained in the repository.
