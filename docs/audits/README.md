# Audit records and scope

These are internal, AI-assisted development reviews produced in separate agent
work sessions. "Independent" means that a reviewer checked the named source or
evidence separately from its author, sometimes before seeing proposed conclusions.
It does not mean external peer review, an independent research group, a human
certification, or statistically independent judgments. Agents can share model
limitations and overlook the same issue.

Each record states what was read, recomputed or executed. A source review does
not certify a GPU run; a saved-trace check does not reproduce training; a passing
test suite does not establish financial usefulness. The underlying source,
manifests, full outcomes and limitations remain the evidence to inspect.
